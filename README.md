# Cutest picture: baby red panda hugging a chick

An entry for make.fun `cutest-picture-01`. The program copies `entry.jpg`
(a baby red panda in a daisy crown hugging a sleeping chick) to
`/output/entry.png`, byte for byte, so both graded runs write identical bytes.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
